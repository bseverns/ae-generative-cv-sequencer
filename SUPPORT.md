# Support

## Project Status

This repository is an experimental hardware and firmware prototype. It is suitable for study, adaptation, bench testing, and careful DIY work. It is not a certified commercial module design.

## Good Issue Reports

Please include:

- Which firmware variant you used: PWM or DAC.
- Hardware revision or build notes.
- Power source and AE bus/context.
- Exact pin mapping if you changed it.
- What you expected to happen.
- What happened instead.
- Measurements, photos, scope captures, serial logs, or patch notes when available.

## Contribution Scope

Useful support includes:

- Hardware corrections and KiCad review.
- Safer input/output protection notes.
- Firmware compile fixes and behavior tests.
- BOM substitutions with electrical justification.
- Panel ergonomics feedback from physical builds.
- Attribution, source, and license corrections.

## Boundaries

This project cannot guarantee compatibility with every AE Modular case, third-party module, power supply, or external CV source. Keep signals in the 0-5 V domain, use a common ground, and verify with a meter before connecting a new build to other gear.

If you build from this repo, you are responsible for the electrical safety of your own hardware.
